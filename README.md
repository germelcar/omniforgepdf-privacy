# OmniForgePDF privacy policy

Public privacy policy for the OmniForgePDF Android app, published with GitHub Pages:

- English: https://germelcar.github.io/omniforgepdf-privacy/ (`index.html`)
- Spanish: https://germelcar.github.io/omniforgepdf-privacy/es/ (`es/index.html`)

Both versions must have the same content. Edit both files in the same commit and set the same
"Last updated" date on each. In-app labels must match the app's strings (Settings → Send crash
reports / Ajustes → Enviar informes de errores). The git history is the version record.
